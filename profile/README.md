*OziExplorer is a GPS navigation and map calibration application for Windows that lets you turn a scanned or digital map into a navigable reference and follow your position on it in real time.*

OziExplorer for Windows fills a specific niche: instead of relying on a generic online map, you work from the actual chart, topo sheet, or survey map relevant to your trip, calibrated so GPS coordinates line up with it exactly. From there, OziExplorer maps become the backdrop for waypoints, planned routes, and recorded tracks, all kept together for a specific area or outing.

## Setting up
Setting up OziExplorer starts with downloading the installer from the button above and running it, accepting the default options unless you have a reason to change them; once installation finishes, the first launch takes you into the main map workspace, ready for you to load or calibrate a map of your own.

## Getting going
1. Load the map image you want to navigate by.
2. Run the calibration tool and mark a handful of known reference points.
3. Connect your GPS receiver so OziExplorer can plot your live position.
4. Drop a waypoint or start a track log to begin recording your route.
